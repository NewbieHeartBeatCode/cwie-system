# cwie-system

ระบบสารสนเทศสหกิจศึกษา (CWIE) คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีราชมงคลรัตนโกสินทร์ ศาลายา
โปรเจกต์รายวิชา CPE 4226 การวิเคราะห์และออกแบบระบบสารสนเทศ สาขาวิศวกรรมคอมพิวเตอร์ (รายละเอียดขอบเขตดูใน `context.md`)

## 🌐 ลิงก์สำหรับทดสอบระบบ (Live Demo)
- **เว็บไซต์หลัก (ล็อกอินตาม Role):** [https://cwie-system.onrender.com](https://cwie-system.onrender.com)
- **หน้าจำลอง 6 บทบาท (Pretest):** [https://cwie-system.onrender.com/pretest](https://cwie-system.onrender.com/pretest)
*(ข้อควรระวัง: หากไม่มีผู้เข้าใช้งานเกิน 15 นาที ระบบจำศีลและลบข้อมูลที่อัปโหลดใหม่ทิ้ง เพื่อรีเซ็ตกลับเป็นข้อมูลตัวอย่างเสมอ การโหลดครั้งแรกอาจใช้เวลา 50 วินาทีเพื่อปลุกเซิร์ฟเวอร์)*

## ข้อมูลมหาวิทยาลัย (ข้อมูลจริง)

- มหาวิทยาลัยเทคโนโลยีราชมงคลรัตนโกสินทร์ (มทร.รัตนโกสินทร์)
- คณะวิศวกรรมศาสตร์ 96 หมู่ 3 ถนนพุทธมณฑล สาย 5 ตำบลศาลายา อำเภอพุทธมณฑล จังหวัดนครปฐม 73170
- หน่วยงานที่ดูแล CWIE: กองสหกิจศึกษา มทร.รัตนโกสินทร์ (coop.rmutr.ac.th, coop@rmutr.ac.th)
- สาขาวิชาในระบบ (ปริญญาตรี คณะวิศวกรรมศาสตร์): วิศวกรรมคอมพิวเตอร์, วิศวกรรมปัญญาประดิษฐ์, วิศวกรรมไฟฟ้า, วิศวกรรมโทรคมนาคม, วิศวกรรมเมคคาทรอนิกส์, วิศวกรรมการวัดคุม, วิศวกรรมเครื่องกล, วิศวกรรมโยธา, วิศวกรรมอุตสาหการ, วิศวกรรมอุตสาหการและการผลิต, วิศวกรรมโลจิสติกส์, วิศวกรรมวัสดุ (ปิโตรเคมีภัณฑ์และพอลิเมอร์)

- สถานประกอบการทั้ง 4 แห่งเป็นบริษัทจริงที่มี MOU สหกิจศึกษากับคณะวิศวกรรมศาสตร์ (จากเอกสาร MOU ของกองสหกิจศึกษา) ที่อยู่/เบอร์โทรจากเว็บไซต์บริษัท แห่งที่ 4 ตั้งสถานะ "รอตรวจสอบ" ไว้สาธิตขั้นตอนตรวจสอบสถานประกอบการ

ชื่อพนักงาน อีเมล login และข้อมูลการฝึกงานในระบบเป็นข้อมูลทดลอง (บัญชีบริษัทใช้ชื่อ "ฝ่ายบุคคล" ไม่ได้อ้างถึงบุคคลจริง)

## วิธีรัน (เปิด 2 terminal)

**backend** API ที่ http://localhost:4000/api
```bash
cd backend
npm install
npm run seed      # สร้างข้อมูลทดลอง (ครั้งแรก หรือเมื่ออยากล้างข้อมูลทดลองใหม่)
npm run dev
```

**frontend** เว็บที่ http://localhost:5173
```bash
cd frontend
npm install
npm run dev
```
frontend ส่ง `/api` ต่อไปที่ backend ให้เอง (vite proxy)
ถ้าพอร์ต 4000 ไม่ว่าง: รัน backend ด้วย `PORT=4100 npm run dev` และ frontend ด้วย `API_PORT=4100 npm run dev`

## โหมดทดสอบ: เปิดทุกบทบาทพร้อมกัน

เปิด **http://localhost:5173/pretest** (หรือกดลิงก์ใต้ปุ่มเข้าสู่ระบบ)
หน้าเดียวเห็นครบ 6 บทบาท แต่ละกรอบ login อัตโนมัติด้วยบัญชีทดลองด้านล่าง

- ทำรายการในกรอบหนึ่ง (เช่น นักศึกษาส่งเอกสาร) แล้วกด **รีเฟรชทั้งหมด** เพื่อดูผลในบทบาทอื่น
- ปรับจำนวนคอลัมน์ / ซูม / ความสูงได้ที่แถบด้านบน
- ปุ่มที่หัวกรอบ: รีเฟรชกรอบนั้น, ขยายกรอบเดียวเต็มจอ, เปิดบทบาทนั้นในแท็บใหม่
- ใช้ได้เฉพาะตอนรัน `npm run dev` (ไม่มีในเวอร์ชัน build จริง)
- ถ้ากรอบไหน login ไม่ได้ ให้รัน `npm run seed` ใน backend ก่อน

นอกจากนี้แต่ละแท็บของเบราว์เซอร์ login แยกกันได้แล้ว (เปิดแท็บหนึ่งเป็นนักศึกษา อีกแท็บเป็นกองสหกิจได้)

## ดูข้อมูล
ฐานข้อมูลเป็นไฟล์ JSON แยก 1 ไฟล์ต่อ 1 ตาราง ใน `backend/database/` เปิดดูและแก้ได้ตรง ๆ

```text
users.json          ผู้ใช้ทุกบทบาท (รหัสผ่านเก็บแบบ hash)
companies.json      สถานประกอบการ
placements.json     การออกฝึก / จับคู่ + ประวัติขั้นตอน
documents.json      เอกสารที่นักศึกษาส่ง + ประวัติการตรวจ
forms.json          แบบฟอร์มให้ดาวน์โหลด
announcements.json  ประกาศ / กำหนดการ
activities.json     บันทึกกิจกรรม / การปฏิบัติงาน
supervisions.json   บันทึกการนิเทศ
evaluations.json    ผลการประเมิน
advices.json        ข้อเสนอแนะจากอาจารย์ที่ปรึกษา
messages.json       ข้อความติดต่อประสานงาน
auditLogs.json      ประวัติการใช้งานระบบ
```
ไฟล์ที่อัปโหลดอยู่ใน `backend/uploads/`
ช่วงพัฒนาเปิดดูผ่านเบราว์เซอร์ได้ที่ `http://localhost:4000/api/dev/data/<ชื่อตาราง>` เช่น `/api/dev/data/placements`

## โครงหลัก
```
frontend/src/
  routes.jsx        หน้า + เมนู + สิทธิ์ของทุกบทบาท (ไฟล์เดียว)
  pages/            หน้าต่าง ๆ (placements/ = การออกฝึก + หน้ารายละเอียด)
  components/       ส่วนประกอบใช้ซ้ำ (FormModal, DocumentList, Table ...)
backend/src/
  routes/index.js   ทุก endpoint + บทบาทที่เรียกได้ (ไฟล์เดียว)
  services/scope.service.js   ขอบเขตข้อมูลที่แต่ละบทบาทมองเห็น
  services/placement.service.js  ขั้นตอนการออกฝึก
  controllers/      logic ของแต่ละเรื่อง
backend/scripts/seed.js        ข้อมูลทดลอง
docs/DFD/         รูปแผนภาพกระแสข้อมูล (PNG + SVG)
```
